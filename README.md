# «Старуха Изергиль» — читатель и подробный пересказ

Одностраничный адаптивный сайт для подготовки к уроку литературы. Приложение работает без библиотек, сборки и API-ключей.

## Возможности

- **Подробный пересказ** произведения, разбитый на 10 смысловых частей для удобства навигации. Это части пересказа, а не официальные главы рассказа.
- **Чтение всего текста** в обычном режиме или в режиме без лишних элементов с увеличенным шрифтом.
- **Скорочтение** — по одному слову на экране, скорость от 60 до 600 слов в минуту.
- Выбор части, настройка размера слова, пауза, продолжение, переход на слово вперёд/назад и перезапуск.
- Управление с клавиатуры: пробел — старт/пауза, стрелки — переход между словами, Esc — выход из полноэкранного режима.
- Адаптация под телефоны и компьютеры.

## Структура

- `index.html` — весь сайт: разметка, стили, пересказ и JavaScript.
- `README.md` — описание проекта и инструкции.

Это намеренно небольшой статический проект: для одной страницы отдельные папки и сборщик не нужны.

## Запуск локально

Откройте `index.html` в браузере. Никаких установок не требуется.

## Публикация через GitHub Pages

1. Откройте репозиторий **Settings → Pages**.
2. В разделе публикации выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)), затем нажмите **Save**.
4. Дождитесь публикации. Сайт будет доступен по адресу: https://canibaa.github.io/staruha-izergil-reader/

Если сайт не обновился, подождите немного и обновите страницу без кэша.

## Важно

Сайт содержит пересказ для подготовки, а не полный оригинальный текст Максима Горького. Пересказ упрощает некоторые детали; для цитат и точного анализа сверяйтесь с текстом произведения.
